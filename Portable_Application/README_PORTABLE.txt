========================================================================
             APPLICATION PORTABLE - COMPARATEUR DE NOTES DE FRAIS
========================================================================

Ce dossier est 100% PORTABLE. Vous pouvez le copier sur n'importe quel ordinateur,
clé USB, disque dur externe ou dossier partagé sans aucune installation.

--- COMMENT UTILISER L'APPLICATION ? ---

Option 1 (Fichier Exécutable .EXE - Recommandée) :
  Double-cliquez simplement sur :
  --> "NoteDeFrais.exe"

Option 2 (Script Batch) :
  Double-cliquez sur :
  --> "Lancer_Application.bat" (ou ouvrez directement "index.html")

Option 3 (Serveur local optionnel) :
  Double-cliquez sur :
  --> "Lancer_Serveur_Local.bat"

--- CONTENU DU DOSSIER PORTABLE ---

- NoteDeFrais.exe          : Application exécutable autonome (.exe Windows).
- index.html               : Application web complète (HTML + CSS + JS autonome).
- Lancer_Application.bat   : Raccourci script batch.
- Lancer_Serveur_Local.bat : Lanceur de serveur HTTP local si besoin.
- Fichiers d'exemples (.xlsx, .json) : Vos données d'exemple pré-chargées.

--- REQUIS ET COMPATIBILITÉ ---
- Fonctionne hors-ligne (sans aucune connexion internet).
- Ne nécessite pas Node.js, npm, ni aucun droits d'administrateur.
- Compatible avec Windows (7 / 8 / 10 / 11).
